JSON

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato utilizado para almacenar y transportar información.

Ejemplo de JSON

{
    "nombre": "Juan",
    "edad": 18,
    "curso": "Programación",
    "activo": true
}

Cómo se usa JSON con APIs

Las aplicaciones pueden solicitar datos a un servidor mediante una API. A menudo, el servidor responde con JSON, que JavaScript puede convertir en objetos para mostrar la información.

fetch("https://ejemplo.com/api/productos")
  .then(respuesta => respuesta.json())
  .then(datos => console.log(datos));
