HTML

¿Qué es HTML?

HTML significa HyperText Markup Language. Es el lenguaje utilizado para crear la estructura de las páginas web.

HTML permite agregar títulos, párrafos, imágenes, enlaces, tablas, formularios y otros elementos.

Ejemplo de HTML

<!DOCTYPE html>
<html>
<head>
    <title>Mi página</title>
</head>

<body>

    <h1>Hola mundo</h1>

    <p>Esta es mi página web.</p>

    <button>Haz clic</button>

</body>
</html>

CSS

¿Qué es CSS?

CSS significa Cascading Style Sheets. Se utiliza para darle diseño y estilo a las páginas web.

Con CSS podemos modificar colores, tamaños, fuentes, espacios, fondos, bordes y mucho más.

Ejemplo de CSS

body {
    background-color: #f4f6f8;
    font-family: Arial;
}

h1 {
    color: #2980b9;
}

button {
    background-color: #3498db;
    color: white;
}

JavaScript

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado para agregar interactividad y funcionalidades a las páginas web.

Ejemplo

function saludar() {
    alert("¡Hola! Bienvenido.");
}

jQuery

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript que permite realizar determinadas tareas de una manera más sencilla.

Ejemplo con jQuery

$("#mensaje").text("Hola desde jQuery");

JSON

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato utilizado para almacenar y transportar información.

Ejemplo de JSON

{
    "nombre": "Juan",
    "edad": 18,
    "curso": "Programación",
    "activo": true
}

JavaScript vs. jQuery

Función JavaScript jQuery
Seleccionar elemento document.querySelector("#boton") $("#boton")
Cambiar texto element.textContent = "Hola" $("#boton").text("Hola")
Ocultar elemento element.style.display = "none" $("#boton").hide()
Mostrar elemento element.style.display = "block" $("#boton").show()
Evento clic addEventListener("click", funcion) $("#boton").click(funcion)
