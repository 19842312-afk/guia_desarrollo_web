Web Hosting y Dominios

¿Qué es Web Hosting?

Es un servicio que guarda los archivos de un sitio web y los entrega a los visitantes a través de internet.

  • Compartido: varios sitios usan los recursos de un servidor.
  • VPS: un servidor virtual con recursos asignados.
  • Nube: utiliza infraestructura de varios servidores.
  • Vercel: plataforma que facilita publicar proyectos web, especialmente sitios estáticos y aplicaciones frontend, conectando repositorios como GitHub.

¿Qué es un dominio?

Es el nombre legible que se utiliza para encontrar un sitio web, por ejemplo, ejemplo.com.

TLD: terminación del dominio, como .com, .net u .org. Subdominio: una parte añadida delante del dominio, como blog.ejemplo.com.

¿Cómo funciona la propagación DNS?

Escribes el dominio
       ↓
El navegador consulta el DNS
       ↓
El DNS encuentra la dirección IP
       ↓
El navegador se conecta al servidor
       ↓
Se muestra la página web

Los cambios DNS pueden tardar en actualizarse en diferentes redes y proveedores.
