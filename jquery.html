jQuery

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript que permite realizar determinadas tareas de una manera más sencilla.

Ejemplo con jQuery

$("#mensaje").text("Hola desde jQuery");

Demostración de jQuery

JavaScript vs. jQuery

Función JavaScript jQuery
Seleccionar elemento document.querySelector("#boton") $("#boton")
Cambiar texto element.textContent = "Hola" $("#boton").text("Hola")
Ocultar elemento element.style.display = "none" $("#boton").hide()
Mostrar elemento element.style.display = "block" $("#boton").show()
Evento clic addEventListener("click", funcion) $("#boton").click(funcion)
